# Dashboard financeiro interativo construído com IA generativa gerando linguagem HTML + JavaScript.

Funções do Dashboard:
- Upload de XLSX
- Pré-classificação automática dos gastos com base no nome do estabelecimento
- Permite que a classificação seja alterada manualmente, já atualizando todos os cálculos
- Visualização dos gastos por categoria
- Visão isolada de cada mês ou resumo de todos os meses
- Exportação de planilha já classificada para checagem dos cálculos
